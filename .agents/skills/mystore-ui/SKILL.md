# MyStore UI Skill

Use the Dribbble reference for visual direction only.

Prioritize:
- original composition
- premium typography
- editorial whitespace
- large furniture imagery
- clean product grids
- responsive behavior
- accessible interactions

Before changing UI:
1. Inspect existing component system.
2. Reuse existing primitives.
3. Check mobile behavior.
4. Implement the smallest coherent change.
5. Use browser verification when available.
6. Fix visual regressions before completion.
