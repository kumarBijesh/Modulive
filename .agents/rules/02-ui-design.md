# MyStore UI Rules

Reference:
https://dribbble.com/shots/25639143-Modulive-Furniture-Landing-Page-E-commerce-Website

Create an original implementation inspired by the reference.

## Visual language
- Premium furniture/editorial aesthetic.
- Neutral warm palette.
- Large imagery.
- Strong editorial typography.
- Generous whitespace.
- Clean navigation.
- Minimal borders and restrained shadows.
- Subtle motion.
- Avoid generic SaaS cards and dashboard styling on storefront pages.

## UX
- Product price and availability must be obvious.
- CTAs must be clear.
- Product cards should be scannable.
- Filters should be usable on mobile.
- Checkout must be calm and focused.
- Forms must show accessible labels and useful errors.
- Never use animation that blocks essential actions.

## Responsive
Design intentionally for mobile, tablet and desktop. Do not merely shrink desktop layouts.

## Accessibility
Use semantic HTML, keyboard navigation, visible focus, proper labels, alt text and reduced-motion support.
