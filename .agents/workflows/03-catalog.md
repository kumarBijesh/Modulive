# MyStore Catalog

Implement the furniture catalog.

## Steps
1. Define Category, Product and ProductImage models.
2. Add validation schemas.
3. Add server-side product/category services.
4. Implement admin CRUD with RBAC.
5. Implement public product listing.
6. Implement product detail pages.
7. Implement search/filter/sort.
8. Add pagination.
9. Add inventory validation.
10. Add audit logs for admin mutations.
11. Build premium responsive UI inspired by the reference.
12. Verify desktop/mobile in browser.
13. Run typecheck/lint/tests.
