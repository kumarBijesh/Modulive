# MyStore Foundation

Build the project foundation in small verified steps.

## Steps
1. Inspect workspace.
2. Confirm Node/npm availability.
3. Initialize or inspect Next.js App Router + TypeScript project.
4. Configure Tailwind and linting.
5. Configure environment validation.
6. Configure Prisma for MongoDB.
7. Add database client abstraction.
8. Add security headers/CSP baseline.
9. Add typed error foundation.
10. Add Zod validation foundation.
11. Add Argon2id password utility.
12. Add audit-log abstraction.
13. Add basic application layout.
14. Add health/check route if appropriate.
15. Run install, typecheck, lint and tests.
16. Fix all failures.
17. Produce an artifact/report summarizing files changed and checks run.

Do not build products, checkout or admin yet.
