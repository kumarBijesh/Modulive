# MyStore Authentication

Implement authentication securely.

## Steps
1. Inspect foundation and Auth.js configuration.
2. Define User model and required auth/session models.
3. Define registration schema.
4. Define login schema.
5. Implement registration with Argon2id.
6. Implement login/session handling.
7. Implement logout.
8. Implement email verification flow.
9. Implement password reset with single-use short-lived tokens.
10. Add rate limiting for login/reset.
11. Add RBAC helpers.
12. Add audit events.
13. Add safe authentication errors.
14. Add tests for success and failure cases.
15. Test invalid input, brute-force throttling and authorization.
16. Run typecheck/lint/tests.
