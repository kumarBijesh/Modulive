# MyStore Cart and Checkout

Implement cart and checkout without trusting the browser.

## Steps
1. Define Cart/CartItem/Order/OrderItem/Payment models.
2. Add validation.
3. Implement guest cart.
4. Implement authenticated cart.
5. Implement cart merge after login.
6. Validate stock server-side.
7. Build checkout address/review flow.
8. Recalculate product prices server-side.
9. Create Stripe TEST checkout/payment flow.
10. Implement verified Stripe webhook.
11. Make webhook/order processing idempotent.
12. Update inventory safely.
13. Create audit events.
14. Add tests for payment success/failure/duplicate webhooks.
15. Run all checks.
