# Implementation Plan

## Sprint 0 — Foundation
Next.js, TypeScript, Tailwind, Prisma, MongoDB, env validation, security headers, errors, logging.

## Sprint 1 — Authentication
Auth.js, registration, Argon2id, login, logout, verification, reset, RBAC, rate limiting.

## Sprint 2 — Catalog
Products, categories, product images, admin CRUD, storefront, search/filter.

## Sprint 3 — Cart
Guest cart, user cart, merge, stock validation, totals.

## Sprint 4 — Checkout
Address, order creation, Stripe test checkout, webhook, payment status.

## Sprint 5 — Admin
Dashboard, inventory, orders, customers, audit logs.

## Sprint 6 — Design Polish
Reference-inspired landing page, responsive design, motion, accessibility, performance.

## Sprint 7 — Quality
Unit tests, API tests, Playwright flows, security review, typecheck, lint.

## Sprint 8 — Deployment
Production environment, MongoDB Atlas, Stripe live mode only after approval/testing, domain, HTTPS, monitoring.
